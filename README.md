# Markdown Live Preview 📑

Type Markdown on the left, see it rendered on the right. Tiny, dependency-free parser.

## What it is
A live Markdown previewer. It ships a tiny built-in parser (headings, bold, italic, code, links, lists) so there are no external dependencies. Type on the left, the rendered result updates on the right.

## Usage
```js
render(markdownText) -> html
```
